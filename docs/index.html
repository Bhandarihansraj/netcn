🚀 netcn Toolbox CDN

A data-driven CDN for .NET toolbox components. Add interactive tools to any project with just 2 lines of HTML. No backend required.

<!-- Step 1: Include the CDN -->
<link rel="stylesheet" href="https://bhandarihansraj.github.io/netcn/cdn/toolbox.css" />
<script src="https://bhandarihansraj.github.io/netcn/cdn/toolbox-engine.js"></script>

<!-- Step 2: Drop a div and you're done! -->
<div class="netcn-toolbox" data-tool="parking-lot"></div>
<div class="netcn-toolbox" data-tool="standard-controls"></div>

⚡ Project Generator

Customize and download ready-to-run ASP.NET projects instantly (like Spring Initializr).

⚙️ Standard Controls

Drag controls from the toolbox and drop them onto the live canvas — just like Visual Studio!

📚 ASP.NET Practicals (1 to 9)

All 9 ASP.NET practicals with C# code + live interactive demos. Try them!

🅿️ Parking Lot

Add, edit, remove, and drag cards between zones. State is saved automatically.
